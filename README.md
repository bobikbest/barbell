# BARBELL — трекер тренировок

Локальное PWA-приложение: без сервера, без бэкенда, все данные лежат в localStorage браузера на устройстве.

## Что изменилось в этой версии

- **Починена иконка.** Раньше `manifest.json` и `index.html` ссылались на `icons/icon-180.png`, `icons/icon-192.png`, `icons/icon-512.png`, а самой папки `icons/` в репозитории не было — только одиночный `icon-512.png` в корне. Теперь папка `icons/` с тремя нужными размерами лежит в архиве.
- **Починена реальная причина багов со стрелками и днями недели.** Даты переводились через `toISOString()`, который работает в UTC. В часовых поясах восточнее UTC (вся Россия) это молча сдвигало дату на день назад — из-за этого стрелка «вперёд» в «Сегодня» будто не работала, а тап по вторнику в «Неделе» открывал понедельник. Теперь дата берётся из локальных полей `Date`, без перехода в UTC.
- **Больше упражнений и осмысленные тренировочные планы.** Каждый шаблон плана теперь подписан, на какой известной методике он основан (Starting Strength Марка Риппето, классический Push/Pull/Legs, золотая эра бодибилдинга, 5/3/1 Джима Уэндлера, схема для тонуса, кроссфит-стиль по мотивам эталонных WOD). В каждом дне больше упражнений, подобранных по группам мышц.
- **Вкладка «Рекорды».** Присед, жим лёжа и становая тяга — отдельными карточками с быстрым обновлением результата. Ниже — свои рекорды: либо выбери упражнение из готового списка (ягодичный мост, жим гантелей на наклонной, армейский жим и т.д.), либо впиши своё.
- **Подсказки при добавлении упражнения.** При создании нового упражнения теперь можно не просто ввести название руками, а выбрать его из списка, сгруппированного по группам мышц (грудь, спина, ноги, плечи, руки, ягодицы, пресс, кардио) — поля (вес/повторы/подходы/высота/время/дистанция) подставятся автоматически, но всё ещё можно донастроить или ввести своё название.
- **Свайп между вкладками.** Смахивай влево/вправо по экрану — переключает «Сегодня» → «Неделя» → «Упражнения» → «Рекорды» → «Настройки» по кругу.

## Как выложить на GitHub Pages

1. Создай репозиторий (или используй существующий), закинь в корень (или в подпапку, например `/app`) все файлы из этой папки: `index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, `icons/`.
2. В настройках репозитория → **Settings → Pages** → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)` (или `/app`, если положил в подпапку).
3. Через минуту-две ссылка будет вида `https://<твой-логин>.github.io/<репозиторий>/`.

### Что конкретно обновить в уже существующем репозитории

- **Заменить целиком:** `app.js`, `styles.css`, `sw.js` — в них все исправления и новые фичи.
- **Добавить новую папку:** `icons/` с тремя файлами (`icon-180.png`, `icon-192.png`, `icon-512.png`) — раньше её не было, из-за этого не показывалась иконка.
- **Удалить:** старый одиночный `icon-512.png` в корне репозитория (если он там лежал) — он больше не нужен, актуальная иконка теперь в `icons/`.
- **index.html и manifest.json** можно тоже просто заменить на версии из этого архива (пути там не менялись, но безопаснее взять актуальные файлы целиком).
- После пуша в GitHub Pages подожди 1–2 минуты и на телефоне сначала удали установленный ярлык с домашнего экрана, зайди в Safari, обнови страницу (иногда помогает Safari → Настройки → Очистить историю и данные сайтов для этого адреса, чтобы сбросить старый service worker), и заново добавь «На экран «Домой»» — тогда подтянется новая иконка и новый код (номер кэша service worker'а увеличен специально, чтобы старая версия не залипала).

## Установка на экран «Домой» (iPhone)

1. Открой ссылку в **Safari** (обязательно Safari, не Chrome).
2. Кнопка «Поделиться» → **«На экран «Домой»»**.
3. Приложение откроется без адресной строки, как обычное приложение, с учётом выреза/Dynamic Island.

## Замена иконки на свою

Когда пришлёшь свою картинку — просто замени три файла в `icons/`, сохранив имена и размеры:
- `icons/icon-180.png` (180×180)
- `icons/icon-192.png` (192×192)
- `icons/icon-512.png` (512×512)

## Что внутри

- **Онбординг** при первом запуске: пол, уровень, дни силовых/кардио, готовый план (с указанием методики) или свой с нуля.
- **Сегодня** — тренировка дня, поля можно сохранить, значения автоматически подставляются в будущем (неделя/месяц/год вперёд), пока не сохранишь новое. Стрелки листают дни.
- **Неделя** — недельная лента, тап по дню открывает его в «Сегодня».
- **Упражнения** — управление списком по дням, добавление/удаление, у каждого упражнения свои поля — например, для жима лёжа поле «высота» можно выключить. При добавлении можно выбрать из подсказок по группам мышц или ввести своё название.
- **Рекорды** — присед/жим/тяга + свои рекорды по любым упражнениям.
- **Настройки** — смена пола/уровня, дней силовых и кардио в любой момент, применение готового плана заново, сброс данных.
- Таббар снизу экрана, с учётом safe-area iPhone 16 Pro. Свайп влево/вправо переключает вкладки.

## Локальная проверка перед публикацией

Из этой папки:
```
python3 -m http.server 8080
```
и открой `http://localhost:8080` в браузере.
